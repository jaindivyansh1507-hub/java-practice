# Java Practice

This repository contains Java practice codes for placements and internships.  
Covers basics → Arrays, Strings, Functions, OOP, Collections, and more.  

## Contents
- Arrays (max, min, reverse, rotate)
- Strings (palindrome, anagram, frequency counter)
- HashMap problems (two sum, subarray sum)

## How to Run
1. Clone this repo
2. Compile with: `javac filename.java`
3. Run with: `java filename`
